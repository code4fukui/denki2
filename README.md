# 第二種電気工事士 模擬試験

第二種電気工事士の学科試験を学習するための、ブラウザ動作の模擬試験アプリです。

## 起動方法

依存ライブラリはありません。プロジェクトのルートでローカルサーバーを起動してください。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。

## 機能

- 全50問、120分タイマー
- 全50問、前半30問（一般問題）、後半20問（配線図問題）から選択
- 問題画像を使った出題
- 問題一覧からの移動、回答済み表示
- 自動採点（100点満点、60点を合格目安）
- 問題ごとの正誤・正答表示
- 誤答を記録し、正解するまで同じ問題に留まる学習モード
- スマートフォン対応

## 出典・利用上の注意

問題および正答は、一般財団法人 電気技術者試験センターが公開している次の資料を使用しています。

- 令和8年度上期 第二種電気工事士学科試験（2026年5月24日実施）
- [第二種電気工事士試験の問題と解答（公式）](https://www.shiken.or.jp/construction/second/qa/index.html)

公式の案内では、教育目的などで公表過去問題を問題集・テキストに使用する場合、許諾および使用料は不要とされています。ただし、著作権は放棄されていません。公式問題を画像として1問単位に切り出しており、学習用アプリ向けに加工しています。

本アプリを教育目的以外で公開・配布・販売する場合や、広告等を伴う場合は、利用条件を確認のうえ、必要に応じて試験センターへ問い合わせてください。
